OOP by design.

Database rows become proper Java objects — the Student model encapsulates every field.

public class Student { private String name; // encapsulation: private String contact; // private fields, private String teachSkill; // public getters/setters private String learnSkill; public Student(String name, String contact, String teachSkill, String learnSkill) { ... } public String getName() { return name; } public String getTeachSkill() { return teachSkill; } ... }

Encapsulation

Student hides its fields; the UI only talks to getters.

Separation of concerns

Frames handle UI, DBConnection handles JDBC, Student is the model.

Safe data access

Every query is a PreparedStatement — no SQL injection, Oracle and SQLite alike.

Get started in 2 minutes.

Pick your flavor. Both compile with JDK 17.

1SQLite — zero setup

Database file + tables are created automatically. Best for trying it now.

cd sqlite javac -cp .:sqlite-jdbc.jar:slf4j-api.jar:slf4j-simple.jar *.java java -cp .:sqlite-jdbc.jar:slf4j-api.jar:slf4j-simple.jar SkillSwapApp

2Oracle — college version

Run schema.sql once, set your credentials in DBConnection.java.

cd oracle javac -cp .:ojdbc11.jar *.java java -cp .:ojdbc11.jar SkillSwapApp
